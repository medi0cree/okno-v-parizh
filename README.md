# Окно в Париж — сайт ресторана (Кизляр)

Анимированный сайт ресторана «Окно в Париж»: ул. Циолковского, 1/1, Кизляр, Республика Дагестан · 8 (928) 046-65-67 · ежедневно 10:00–23:00, завтраки до 14:00.

## Возможности
- Прелоадер «ставни», SVG-сцена «вид из окна» с параллаксом (Париж + горы Кавказа)
- Меню-витрина: 123 блюда, подбор по настроению, 11 вкусовых фильтров, фильтр цены, поиск, «Удивите меня»
- Карточка блюда с похожими блюдами, «Мой столик» с подсчётом суммы и звонком / WhatsApp
- Бар (кофе, чай, лимонады, фреши, коктейли, кальян) в виде грифельной доски
- Конструктор банкета с расчётом на гостя
- Контакты, часы с отметкой «открыто сейчас», Яндекс Карта, schema.org Restaurant

## Стек
React 19 · TanStack Start (SSR) · Vite 7 · Tailwind CSS v4 · GSAP + ScrollTrigger · Lenis · Motion · Embla Carousel · Cloudflare Workers

## Запуск
Нужны Node.js 20.19+ (или 22.12+) и Bun.

```bash
cd app
bun install
bun run dev       # локальная разработка
bun run build     # сборка: dist/server (Worker) + dist/client
```

Деплой на Cloudflare Workers: `npx wrangler deploy` из папки `app` (настройки в `app/wrangler.jsonc`).

## Где что лежит
- `app/src/routes/index.tsx` — главная страница
- `app/src/components/okno/` — блоки сайта
- `app/src/data/` — меню кухни, бара и банкета (цены с oknorest.ru)
- `app/src/lib/okno.ts` — контакты, часы, теги вкусов, сценарии настроения
- `app/src/okno.css` — фирменный стиль (палитра, шрифты, анимации)
- `app/public/assets/menu/` — фото блюд (WebP)

Цены взяты из меню ресторана и могут меняться.
