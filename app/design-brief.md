# Окно в Париж — дизайн-бриф

- Design read: жители и гости Кизляра, семьи и компании; тёплый вечерний регистр, «праздник рядом с домом».
- Concept spine: сайт как окно. Одно окно смотрит сразу на Париж и на Кавказ; ставни открываются при входе, вид из окна живёт при прокрутке, меню оформлено как витрина.
- Delivery tier: cinema (Lenis + GSAP ScrollTrigger + Motion).
- Locked palette: ночь #0F1B2D / #16263D, цинк крыш #C9D4DE, бумага #F2F3EF, маркиза-гренадин #D6453D, фонарь #F4C95D, мох #2F5D50. Синий + красный + золото: парижская маркиза ночью, мох и зелень: горы.
- Locked type: Cormorant Garamond (вывески брассери, italic для акцентов), Manrope (текст и интерфейс), Marck Script (надписи мелом и заметки официанта). Все с кириллицей.
- Animation mode: non-animated — user picked «Анимированный», но без генерации (0 кредитов Higgsfield), поэтому фильм для scroll-scrub не создан; вместо него кодовая анимация: CSS-ставни, SVG-сцена с параллаксом, GSAP-подъёмы, Motion layout-фильтры.
- Section plan: ставни → hero (окно-сцена) → лента → «Два берега» (сплит) → коронные блюда (карусель Embla) → меню-витрина с подбором по вкусу → бар-грифельная доска → конструктор банкета (билет) → цифры → контакты с картой → подвал.
- Asset plan: реальные фото блюд с oknorest.ru (152 шт.), собственная SVG-сцена окна, собственные иконки вкусов, SVG-знак окна, favicon, OG собран из фото ресторана.
- CTA inventory: «Подобрать блюдо» (заливка-шторка), телефон в hero (подчёркивание), «Позвонить» в навигации (подъём фона), «Удивите меня» (вращающийся кубик), «+» в карточке (поворот на 90°), «Мой столик» (выезжающий лоток), «Обсудить банкет» (блик), большой телефон (перелив текста), ссылки маршрутов (рамка-фонарь).
